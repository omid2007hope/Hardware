# CPU Architectures

- **x86 / x64:** The processor architecture used by **Intel** and **AMD** chips (found in most Windows PCs, Linux servers, and older Macs).
- **ARM64 (AArch64):** The 64-bit architecture used in modern mobile phones, tablets, **Apple Silicon** (M1/M2/M3/M4 Macs), and ARM servers.
- **Fallback:** Backup code that runs if the program is compiled on any CPU architecture *other* than x86/x64 or ARM64 (e.g., RISC-V or 32-bit processors).
